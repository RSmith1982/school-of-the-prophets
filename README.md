# The School of The Prophets

Website for the ministry school. A single static page (`index.html`) with no build step.

## Put it on GitHub Pages

1. Create a new repository on GitHub (for example `school-of-the-prophets`).
2. Upload `index.html` and this `README.md` to the repository (drag and drop on the GitHub website works).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then save.
5. After a minute the site is live at `https://<your-username>.github.io/school-of-the-prophets/`.
